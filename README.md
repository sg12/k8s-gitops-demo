# k8s-gitops-demo

Учебный репозиторий к Вебинару 11 курса «Оркестрация и контейнеризация» (МИФИ): GitOps и Argo CD.

| Папка | Что внутри | Как использует Argo CD |
|---|---|---|
| `apps/hello/` | Deployment и Service приложения `hello` (образ `traefik/whoami`) — обычные YAML-файлы | Application `hello`, `path: apps/hello` |
| `charts/hello/` | Тот же сервис в виде Helm-чарта: число копий, образ и подпись — в `values.yaml` | Application `hello-helm`, `path: charts/hello` |

## Как работать со своей копией

1. Войдите в GitHub и нажмите **Fork** вверху этой страницы — у вас появится копия `github.com/<ваш-логин>/k8s-gitops-demo`.
2. В файле Application из тьюториала замените в `repoURL` логин `sg12` на свой.
3. Менять файлы можно прямо в браузере: откройте файл → значок карандаша (**Edit**) → внесите правку → **Commit changes**.
4. Argo CD заметит изменение в течение ~3 минут; сразу — кнопка **Refresh** в интерфейсе Argo CD.

Без аккаунта GitHub можно подключить этот репозиторий как есть — всё, кроме правок в Git, работает.
